**Q1** Yes — `sidebarAction.show({url})` is browser-internal (Whale-only, not a Naver web service). **Q2** Yes — any page can nudge the user to install/trigger a sidebar extension, or an XSS on an already-installed extension can call `show()` with an arbitrary URL. **Q3** Yes — cross-origin data theft / credential exfiltration from a browser-UI context; Critical if it escalates to renderer. **Q4** **No** — proof requires installing the binary and driving `show({url})` with crafted HTML (runtime, not GET/HEAD). Wiki doc review is already exhausted (the drag-nav exposure is a *documented* mitigation, not a bypass). **Q5** Yes — no 2026 CVE; NVD CPE for CVE-2025-69235 lists only Win/macOS, leaving Linux unclaimed. **Q6** Yes — not on the reject list. **Q7** Borderline — strong precedent (6 sidebar/dual-tab CVEs in 2025) but no runtime proof.

**Verdict: HOLD** — fails Q4; requires binary install + runtime repro.
